# 위젯 설정 드로어 — 프로그램 명세

**작성 기준**: `WidgetSettingDrawer.jsx` 및 parseType별 Fields 컴포넌트

***

## 1. 데이터 구조와 흐름

### 1.1 진입 조건

| SWR Key                        | 값                                        | 설명        |
| ------------------------------ | ---------------------------------------- | --------- |
| `drawer-opened`                | `'widget-manager'`                       | 위젯 관리자 열림 |
| `widget-setting-drawer-target` | `{ targetType, widgetId, options, ... }` | 설정 대상     |

* 저장: `targetType === 'group'`만 API 저장
* 신규 그룹(`widgetId == null`): 로컬 상태만 갱신, `parseType` 없으면 생성 불가

### 1.2 form 기본 필드

`unit`, `measurementUnit`, `formulaExample`, `rodLength`, `appliedFormula`, `values`, `sensorList`, `chartType`, `parseType`

별도: `widgetName`, `saving`, `commonThresholdRows`, `channelThresholdGroups`

### 1.3 상세 진입 프로세스

1. `target.options` clone
2. legacy key 제거 (`sensorIds`, `channels`, `groupSetting`)
3. `parseType` 결정: options → groupSetting → lora channel → ''
4. parseType별 `sensorList` 재구성
5. formula/chartType 정규화
6. 기준치: **별도 threshold 테이블**만 (options threshold 미사용)

### 1.4 parseType별 상단 Fields

| parseType | 컴포넌트                        | 핵심                               |
| --------- | --------------------------- | -------------------------------- |
| `gdms`    | `WidgetSettingGdmsFields`   | 차트 옵션, 지점 표시, 누적 방향,             |
| `lora`    | `WidgetSettingLoraFields`   | A/B singleOutput, valNN / output |
| `fft`     | `WidgetSettingFftFields`    | analysisType, valueTemplates     |
| `geocus`  | `WidgetSettingGeocusFields` | formula 토큰, sensorList values    |

### 1.5 GDMS 전용 필드

`WidgetSettingGdmsFields`는 계산식 필드 위아래로 세 가지 옵션을 둔다.

| UI 라벨         | 저장 필드                     | 값                                        | 비고                                                             |
| ------------- | ------------------------- | ---------------------------------------- | -------------------------------------------------------------- |
| 차트 옵션         | `gdmsChartOption`         | `vertical` / `horizontal` / `semicircle` | 라벨은 `GDMS_CHART_OPTION_LABELS`(수직 지중경사계 / 수평 도상침하계 / 반원 내공변위계) |
| 지점으로 표시       | `gdmsPointAccumulate`     |                                          |                                                                |
| 디테일 테이블 누적 방향 | `gdmsAccumulateDirection` | `ltr`(1채널 → N채널) / `rtl`(N채널 → 1채널)      | 지점 표시 모드에서는 비활성                                                |

* 세 값은 저장 전 `normalizeGdmsChartOption` / `normalizeGdmsPointAccumulate` / `normalizeGdmsAccumulateDirection`을 통과한다. 미인식 값은 각각 `vertical`, `true`, `ltr`로 정규화된다.
* 계산식은 `formulaExample` 하나를 공통으로 쓰고, `extractFormulaTokens(formula).settingTokens`로 뽑은 토큰(`${로드길이}` 등)을 입력 필드로 노출한다.
* 차트 옵션이 상세 드로어에서 어떤 차트로 이어지는지는 [19-위젯-그리드-상세-드로어.md](19-%EC%9C%84%EC%A0%AF-%EA%B7%B8%EB%A6%AC%EB%93%9C-%EC%83%81%EC%84%B8-%EB%93%9C%EB%A1%9C%EC%96%B4.md)를 본다.

### 1.6 LoRa 출력 모드

* 개별출력 (`singleOutput=false`): 채널1개당 출력 1
* 단일출력 :(`singleOutput=true`): 설정된 채널 n개당 출력 1개개

### 1.7 저장 흐름

```
saveAll → buildOptionsForSave(parseType)
  → sensorWidgetService.update/create
  → useWidgetManagerGroups 상태 갱신
  → threshold save (별도)
  → 상태 mutate
```

## 2. 관련 파일과 주요 함수

| 파일                                       | 역할                                                                                                                   |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `WidgetSettingDrawer.jsx`                | form·저장·기준치                                                                                                          |
| `WidgetSettingSensorList.jsx`            | 센서 item 편집                                                                                                           |
| `WidgetSettingCommonThreshold.jsx`       | 공통 기준치                                                                                                               |
| `widgetSettingFormulaTokenUtils.js`      | formula 토큰                                                                                                           |
| `widgetSettingSensorItemFormulaUtils.js` | item formula, `resolveItemColumnName`                                                                                |
| `widgetSettingThresholdUtils.js`         | 기준치 row                                                                                                              |
| `widgetThresholdRows.js`                 | threshold row 빌드                                                                                                     |
| `useWidgetManagerGroups.js`              | 로컬/DB 그룹 연동                                                                                                          |
| `WidgetSettingGdmsFields.jsx`            | GDMS 차트 옵션·지점 표시·누적 방향                                                                                               |
| `gdmsWidgetCalculations.js`              | `GDMS_CHART_OPTIONS`, `normalizeGdmsChartOption`, `normalizeGdmsPointAccumulate`, `normalizeGdmsAccumulateDirection` |
