## 작성 형식

각 기능은 아래 순서로 기술한다.

1. **기능 설명** — 무엇을 위한 기능인지, 왜 필요한지
2. **화면 구성** — 사용자가 보는 영역·항목
3. **사용 절차** — 단계별 조작
4. **표시 규칙** — 값·상태에 따른 화면 변화 (해당 시)
5. **예외 처리** — 데이터 없음, 권한 없음, 저장 실패 등

## 용어

| 용어 | 설명 |
| --- | --- |
| 현장 | 모니터링 대상 구역. 로그인 후 표시되는 제목이 현장명이다. |
| 센서 | 측정 장치에서 들어오는 데이터 단위 |
| 위젯 | 대시보드에 배치되는 표시 단위(게이지, 차트, 목록, CCTV 등) |
| 그룹 | 위젯 관리자에서 센서·CCTV를 묶어 두는 단위 |
| 기준치 | 측정값이 위험 수준인지 판단하는 임계값 |
| 상세 조회 | 센서·위젯을 선택해 기간별 차트와 기록을 보는 화면 |
