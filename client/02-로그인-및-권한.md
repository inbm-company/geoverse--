# 02. 로그인 및 권한

## 2.1 로그인

### 기능 설명

승인된 사용자만 시스템에 접속할 수 있도록 아이디와 비밀번호로 본인 확인을 한다. 로그인에 성공하면 해당 사용자에게 허용된 현장 대시보드로 이동한다.

### 화면 구성

| 영역 | 설명 |
| --- | --- |
| 현장 제목 | 접속 대상 현장 이름 |
| 아이디 입력 | 텍스트 입력 |
| 비밀번호 입력 | 비밀번호 입력 |
| 로그인 버튼 | 제출 |
| 자동 로그인 | 선택 시 다음 접속 때 로그인 정보 유지 |

### 사용 절차

1. 브라우저에서 시스템 주소에 접속한다.
2. 아이디와 비밀번호를 입력한다.
3. **로그인**을 누른다.
4. 성공 시 대시보드가 표시된다.

### 예외 처리

- 아이디 또는 비밀번호가 틀리면 오류 메시지가 표시되고, 대시보드로 이동하지 않는다.
- 로그인 처리 중에는 버튼이 비활성화되어 중복 요청을 막는다.

---

## 2.2 자동 로그인(세션 유지)

### 기능 설명

이전에 로그인한 적이 있으면 브라우저를 다시 열었을 때 로그인 화면 없이 대시보드로 바로 들어갈 수 있다.

### 표시 규칙

- 저장된 로그인 정보가 유효하면 대시보드를 연다.
- 만료되었거나 없으면 로그인 화면을 연다.

---

## 2.3 로그아웃

### 기능 설명

현재 사용자의 접속을 종료하고 로그인 화면으로 돌아간다.

### 사용 절차

1. 상단 오른쪽 **사용자 아이콘**을 클릭한다.
2. **로그 아웃**을 선택한다.
3. 로그인 화면으로 이동한다.

### 예외 처리

- 로그아웃 요청이 실패하면 알림으로 안내한다.

## 2.4 권한별 메뉴

### 기능 설명

사용자 등급에 따라 상단에 보이는 관리 메뉴가 달라진다. 모바일 화면에서는 관리 메뉴 전체가 숨겨진다.

### 메뉴 목록

| 메뉴 | 일반 사용자 | 관리자 | 최고 관리자 |
| --- | --- | --- | --- |
| 디바이스 관리자 | — | — | ○ |
| 디바이스목록 | — | — | ○ |
| 센서목록 | — | — | ○ |
| 위젯 관리자 | — | ○ | ○ |
| 기준치설정 | ○ | ○ | ○ |
| 알림로그 | ○ | ○ | ○ |
| 사용자 관리 (사용자 메뉴) | — | ○ | ○ |

### 예외 처리

- 권한이 없는 메뉴는 화면에 표시되지 않는다.

## 2.5 숨김 메뉴 (최고 관리자)

### 기능 설명

최고 관리자는 일반 메뉴 외에 더블클릭으로 특정 화면에 바로 진입할 수 있다.

| 조작 | 열리는 화면 |
| --- | --- |
| 로고 더블클릭 | 디바이스 관리자 |
| 현장명 영역 더블클릭 | 시스템 모니터 |

## 2.6 화면 테마

### 기능 설명

상단의 스위치로 밝은 테마와 어두운 테마를 전환한다. 선택은 브라우저에 저장되어 다음 접속 때도 유지된다.

### 사용 절차

1. 상단 오른쪽 **해/달 아이콘 스위치**를 클릭한다.
2. 전체 화면 색상이 밝은 모드 또는 어두운 모드로 바뀐다.
