# 임계치·상태 계산·엑셀 — 프로그램 명세

**작성 기준**: `useThresholds.js`, `thresholdService.js`, `excelExport.js`, `excelImport.js`

***

## 1. 데이터 구조와 흐름

### 1.1 임계치 상태관리

| Key               | 용도        |
| ----------------- | --------- |
| `site-thresholds` | 현장 기준치 캐시 |

**조회**: `useThresholds()` → `getThresholdBySensor(deviceId, channel, fieldName)`

**저장**: `ThresholdSettingDrawer` → `saveThresholds(siteCode, thresholds)` →상태갱신

### 1.2 기준치 테이블 모드

| 모드     | 조건                                          | 데이터 소스                |
| ------ | ------------------------------------------- | --------------------- |
| 정적레이아웃 | `isLegacySiteChartsSite` \|\| `isBentoSite` | `getSiteGauges()`     |
| 동적레이아웃 | 그 외                                         | `buildWidgetGroups()` |

### 1.3 useGaugeData 상태 판정

```
gauge-sensor-data + useThresholds + calculation
  → value, status(normal/warning/danger), timestamp, thresholds
```

* 유량: 일별 파생 계산
* 풍향 등 예외 타입 별도 규칙

### 1.4 BaseTable (상세 로그)

입력: `apiResults`, `initialResults`, `sensors`, `sensorType`

→ `createTableData` / `createTableColumns` → `setExcelData`

### 1.5 엑셀

| 모듈               | 역할                             |
| ---------------- | ------------------------------ |
| `excelExport.js` | 다단 헤더, 파일명(센서·기간·RAW)          |
| `excelImport.js` | 시트 파싱, timestamp 행, 레코드 병합, 검증 |

***

## 2. 관련 파일과 주요 함수

| 파일                                  | 역할             |
| ----------------------------------- | -------------- |
| `hooks/useThresholds.js`            | SWR 기준치        |
| `services/thresholdService.js`      | fetch/save API |
| `services/alarmLogService.js`       | 알림 로그          |
| `ThresholdSettingDrawer.jsx`        | 편집 UI          |
| `hooks/useGaugeData.js`             | 게이지 값·상태       |
| `table/BaseTable.jsx`               | 상세 로그 표        |
| `utils/table/tableDataConverter.js` | 보조 변환(레거시)     |

***

## 3. 사용 컴포넌트 설명

| 컴포넌트                     | 설명                                  |
| ------------------------ | ----------------------------------- |
| `ThresholdSettingDrawer` | App + Dashboard (threshold-setting) |

## 4. 구현 시 주의사항

1. 임계치 키(`deviceId`, `ch`, `fieldName`)와 게이지 매칭 동시 수정.
2. BaseTable 컬럼 변경 시 import/export 함께 점검.
3. 센서 타입별 warning/danger 규칙 분리 유지.
