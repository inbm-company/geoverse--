# 04. 상세 조회

## 4.1 개요

### 기능 설명

대시보드에서 센서·위젯·게이지·조감도 마커를 선택하면 **기간별 측정 데이터**를 차트와 표로 자세히 볼 수 있는 화면이 열린다.

- 언제부터 언제까지의 데이터인지 기간을 바꿀 수 있다.
- 차트로 추이를 보고, 아래 표에서 시각별 수치를 확인한다.
- 필요하면 **인쇄**하거나 **엑셀 파일**로 내려받을 수 있다.
- 권한이 있으면 엑셀 파일을 다시 올려 측정값을 수정·반영할 수 있다.

현장·센서 종류에 따라 차트·표 형태가 달라진다. 사용자 입장에서는 모두 「상세 조회」이지만, **지중경사계**처럼 깊이별 프로파일을 보는 화면은 일반 시계열과 구성이 다르다.

---

## 4.2 상세 조회 열기

### 기능 설명

대시보드에서 데이터를 더 자세히 보고 싶을 때 상세 조회로 진입한다.

### 진입 방법

| 조작 | 대상 |
| --- | --- |
| 게이지·숫자 클릭 | 해당 센서 |
| 위젯 카드 클릭 | 해당 위젯 (그리드형 현장) |
| 조감도 마커 클릭 | 연결된 센서 (고정형 현장) |

### 사용 절차

1. 대시보드에서 보고 싶은 센서·위젯을 클릭한다.
2. 화면 옆(또는 전체)에 상세 조회 패널이 열린다.
3. 기본 기간의 차트·표가 로드된다.

### 예외 처리

- 모바일에서는 위젯 상세 조회가 열리지 않는다.
- CCTV·현장 정보 전용 위젯은 상세 조회 대상이 아니다.
- 데이터가 없으면 「데이터 없음」 또는 빈 차트·표가 표시된다.

---

## 4.3 기간 선택

### 기능 설명

조회할 시작·종료 일시를 바꿔 해당 구간의 데이터만 다시 불러온다.

### 화면 구성

| 항목 | 설명 |
| --- | --- |
| 시작 일시 | 조회 구간 시작 |
| 종료 일시 | 조회 구간 끝 |
| 새로고침 | 선택한 기간으로 다시 조회 |

### 사용 절차

1. 상단의 시작·종료 날짜·시간을 선택한다.
2. 조회가 자동으로 갱신되거나 새로고침 버튼을 누른다.
3. 차트와 표가 선택 기간 기준으로 바뀐다.

### 예외 처리

- 센서 설치 이전 날짜는 선택할 수 없도록 제한될 수 있다.
- 기간이 너무 길면 로딩 시간이 길어질 수 있다.

---

## 4.4 일반 상세 조회 (시계열)

### 기능 설명

대부분의 센서는 시간에 따른 측정값 변화를 **선 그래프(차트)** 와 **기록 표**로 보여 준다.

### 화면 구성

| 영역 | 설명 |
| --- | --- |
| 기간 선택 | 4.3과 동일 |
| 차트 | 선택 기간 동안의 측정값 추이 |
| 요약 표 | 구간 내 최대·최소 등 요약 (센서 종류에 따라) |
| 로그 표 | 시각별 측정값 목록 |

### 표시 규칙

| 센서 종류 | 추가 옵션 |
| --- | --- |
| 유량계 | 시간별 / 일별 보기 전환 |
| 수위계 | 수위 / 누적 수위 보기 전환 |
| 고주파(FFT) | 주파수 분석용 별도 차트·이미지 (현장 설정에 따름) |

### 사용 절차

1. 차트에서 추이를 확인한다.
2. 아래 표에서 특정 시각의 수치를 찾는다.
3. 필요 시 범례를 클릭해 특정 항목만 차트에 표시·숨김할 수 있다.

---

## 4.5 지중경사계 상세 조회

### 기능 설명

지중경사계는 깊이마다 변위가 다르게 측정된다. 상세 조회에서는 **깊이별 프로파일 차트**와 **축별 요약·기록**을 제공한다.

### 화면 구성

| 영역 | 설명 |
| --- | --- |
| 차트 | 깊이(세로) × 누적 변위(가로) 프로파일. A축·B축 등 축별로 패널이 나뉠 수 있음 |
| 요약 | 축별 합계 값의 구간 내 최대·최소 |
| 로그 | 시각별·깊이별 원본 기록 |

### 사용 절차

1. 위젯 또는 센서를 클릭해 상세 조회를 연다.
2. 기간을 선택한다.
3. 프로파일 차트에서 깊이별 변형 형태를 확인한다.
4. 요약·로그 표에서 수치를 확인한다.

### 예외 처리

- 축이 하나만 설정된 경우 해당 축 패널만 표시된다.

---

## 4.6 인쇄

### 기능 설명

상세 조회 화면의 차트·표를 인쇄용 레이아웃으로 정리해 출력한다.

### 사용 절차

1. 상세 조회를 연다.
2. 인쇄 메뉴(또는 인쇄 버튼)를 선택한다.
3. 미리보기에서 범위를 확인하고 인쇄한다.

지중경사계는 프로파일 차트와 로그 표가 함께 인쇄 레이아웃에 포함된다.

---

## 4.7 엑셀 내보내기

### 기능 설명

상세 조회의 기록 표 내용을 엑셀 파일로 저장한다. 보고·외부 공유·오프라인 분석에 사용한다.

### 사용 절차

1. 상세 조회에서 조회 기간을 맞춘다.
2. **다운로드(엑셀)** 버튼을 누른다.
3. 파일이 저장된다.

### 표시 규칙

| 센서 유형 | 파일 형태 |
| --- | --- |
| 일반 센서 | 시각·항목별 열로 구성된 시트 |
| 지중경사계 | 축별로 시트가 나뉘거나, 깊이·시각 매트릭스 형태 |

---

## 4.8 엑셀 가져오기 (측정값 수정)

### 기능 설명

최고 관리자 등 권한이 있는 사용자는 내려받은 엑셀을 수정한 뒤 다시 올려 서버의 측정값을 갱신할 수 있다. 현장 보정·누락 보완 등에 사용한다.

### 사용 절차

1. 먼저 해당 구간을 엑셀로 내보낸다.
2. 엑셀에서 값을 수정한다.
3. 상세 조회에서 **업로드** 버튼을 누르고 파일을 선택한다.
4. 확인 후 반영되면 차트·표가 갱신된다.

### 예외 처리

- 파일 형식이 맞지 않으면 업로드가 거부된다.
- 권한이 없는 사용자에게는 업로드 버튼이 보이지 않는다.
- 일부 센서 설정에서는 엑셀 수정 기능이 제공되지 않을 수 있다.

---

## 4.9 현장 유형별 차이 요약

| 구분 | 진입 | 상세 화면 특징 |
| --- | --- | --- |
| 고정형 대시보드 | 게이지·마커 클릭 | 현장별로 정의된 센서 목록 기준 |
| 그리드형 대시보드 | 위젯 카드 클릭 | 위젯 설정에 따른 항목·차트 |
| 지중경사계 | 위젯·센서 클릭 | 프로파일 차트 + 축별 로그 |

사용자는 현장 유형을 구분할 필요 없이 **클릭 → 기간 선택 → 차트·표 확인** 흐름은 동일하다.
