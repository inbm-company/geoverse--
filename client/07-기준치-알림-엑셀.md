# 07. 기준치, 알림, 엑셀

## 7.1 기준치 설정

### 기능 설명

센서 측정값이 어느 수준을 넘으면 **주의·위험**으로 볼지 정하는 기능이다. 기준치를 저장하면 대시보드 게이지·목록·차트에 **색상**이 적용되고, 기준을 넘긴 경우 **알림 이력**에 기록될 수 있다.

현장·운영 기준마다 숫자가 다르므로 사용자가 직접 입력한다.

### 화면 구성

상단 메뉴 **기준치설정**을 누르면 센서(또는 위젯) 묶음별 **표**가 열린다.

| 열 | 설명 |
| --- | --- |
| key | 센서·항목 식별 (읽기 전용) |
| 1차 | 1단계 기준값 |
| 2차 | 2단계 기준값 |
| 3차 | 3단계 기준값 |
| 지속(초) | 이 시간 이상 초과해야 알림 |
| 휴지(분) | 알림 후 재알림까지 대기 시간 |
| ± | 양·음 방향 모두 적용 여부 |

현장 유형에 따라 표에 나오는 **행 묶음** 방식이 다를 수 있다.

- **고정형 현장**: 미리 정의된 게이지·센서 목록 기준
- **그리드형 현장**: 위젯·그룹별로 행이 구성됨

### 사용 절차

1. **기준치설정** 메뉴를 연다.
2. 대상 센서·항목 행을 찾는다.
3. 1차·2차·3차 값과 필요 시 지속·휴지·±를 입력한다.
4. **저장**을 누른다.
5. 대시보드로 돌아가면 해당 센서 색상 반영을 확인한다.

### 표시 규칙

| 측정값 조건 | 대시보드 표시 |
| --- | --- |
| 모든 기준 미만 | 정상 (기본 색) |
| 1차 이상, 2차 미만 | 주의 (노란 계열) |
| 2차 또는 3차 이상 | 위험 (빨간 계열) |

유량 등 일부 센서는 **일별 합산값**으로 판정할 수 있다.

### 예외 처리

- 기준치를 입력하지 않은 항목은 색 구분 없이 표시된다.
- 저장 실패 시 입력값은 유지되고 오류 안내가 표시된다.

## 7.2 게이지·위젯 상태 색

### 기능 설명

기준치 저장 후, 실시간으로 들어오는 측정값과 비교해 카드·게이지·막대에 색이 붙는다. 사용자는 숫자와 색만으로 위험 여부를 빠르게 파악한다.

### 표시 규칙

- 헤더·대시보드 게이지, 그리드 위젯 카드, 막대 차트 항목에 동일한 기준이 적용된다.
- 기준치를 바꾸고 저장하면 이후 수신 데이터부터 새 기준이 적용된다.

## 7.3 알림 로그

### 기능 설명

기준을 넘겨 알림이 발생한 **이력**을 날짜별로 조회한다. 언제 어떤 센서가 어떤 단계 기준을 넘었는지 확인할 때 사용한다.

### 화면 구성

| 영역 | 설명 |
| --- | --- |
| 제목 | 알람 로그 |
| 목록 | 날짜별로 묶인 알림 항목 |
| 조회 조건 | 기간·건수 (화면 제공 범위) |

### 사용 절차

1. 상단 **알림로그** 메뉴를 클릭한다.
2. 목록에서 날짜·항목을 확인한다.
3. 필요 시 스크롤해 더 많은 이력을 본다.

### 예외 처리

- 해당 기간에 알림이 없으면 「조회된 알람 로그가 없습니다」 안내가 표시된다.
- 로딩 중에는 로딩 안내가 표시된다.

## 7.4 사용자 관리

### 기능 설명

관리자가 현장 사용자 계정을 추가·수정·삭제하고, **기준치 단계별 알림 수신 대상**을 지정한다.

### 화면 구성

| 영역 | 설명 |
| --- | --- |
| 사용자 목록 | 아이디, 이름, 권한 등 |
| 추가·수정 | 사용자 정보 입력 |
| 알림 수신 설정 | 1·2·3차 기준별 수신자 |

### 사용 절차

1. 사용자 아이콘 → **사용자 관리**를 연다.
2. **사용자 추가** 또는 기존 행 **수정**을 선택한다.
3. 정보 입력 후 저장한다.
4. 알림 수신 섹션에서 단계별 수신자를 지정한다.

### 예외 처리

- 관리자 권한이 없으면 메뉴가 보이지 않는다.
- 현장 코드가 맞지 않으면 목록을 불러오지 못할 수 있다.

## 7.5 상세 조회 — 기록 표

### 기능 설명

[04-상세-조회.md](./04-상세-조회.md) 화면 하단 **로그** 영역에 시각별 측정값이 표로 나온다. 센서 종류에 따라 열 구성·표시 모드(유량 시간/일별, 수위/누적 수위 등)가 달라진다.

### 사용 절차

1. 상세 조회를 연다.
2. 기간을 선택한다.
3. 로그 표에서 행·열을 확인한다.

## 7.6 엑셀 내보내기·가져오기

### 기능 설명

상세 조회의 기록을 엑셀로 저장하거나, 수정한 엑셀을 다시 올려 반영한다. 상세한 절차는 [04-상세-조회.md](./04-상세-조회.md) 4.7·4.8절과 동일하다.

| 작업 | 요약 |
| --- | --- |
| 내보내기 | 상세 조회 → 다운로드 버튼 → 파일 저장 |
| 가져오기 | 엑셀 수정 → 업로드 버튼 → 확인 (권한 필요) |

지중경사계는 축·깊이별로 시트 구성이 다를 수 있다.

---

## 7.7 기능 간 관계

```text
기준치 설정 ──→ 대시보드 색상 · 위험 표시
      │
      └──→ (조건 충족 시) 알림 로그 이력

상세 조회 ──→ 기록 표 ──→ 엑셀 내보내기 / 가져오기

사용자 관리 ──→ 알림 수신 대상 지정
```

일반 사용자는 **기준치 설정·알림 로그 조회·상세 엑셀 다운로드**를 주로 사용하고, **엑셀 업로드·사용자 관리**는 관리자·최고 관리자가 담당한다.
