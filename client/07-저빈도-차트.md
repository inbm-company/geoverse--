# 저빈도 차트 — 프로그램 명세

**작성 기준**: `LowFrequencyChart.jsx`, `useLowFrequencySensorData.js`, `sensors/*SensorConfig.js`

---

## 1. 데이터 구조와 흐름

### 1.1 컨테이너 (LowFrequencyChart)

1. `validateSensorConfig(sensorType)`
2. 센서 목록: prop `sensors` → 없으면 `siteConfig` fallback
3. 모드/날짜/MinMax + `useThresholds` markLine
4. `RealtimeChart` | `PeriodChart` 분기
5. 상세보기 → `chart-detail-params` + `drawer-opened`

### 1.2 useLowFrequencySensorData

| 동작 | 설명 |
|------|------|
| 중복 제거 | `sensorId+channel` |
| range | `Promise.all` 병렬 호출 |
| realtime | 소켓 데이터 병합 |
| 결과 | `resultKey` 기준 `processedData` |

**반환**: `processedData`, `loading`, `error`, `refetch`

### 1.3 dataProcessor 계약

```
sensorConfig.dataProcessor(processedData, mode, minMaxState, sensors)
  → LowFrequencyChartManager → createRealtimeChartOptions | createPeriodChartOptions → MainChart
```

### 1.4 센서 타입 라우팅 (sensors/index.js)

tension, strain, inclinometer, expansion, displacement, seismometer, accelerometer, newAccelerometer, wind, windSpeed, windDirection, tempHumidity, waterLevel, flow

**함수**: `getSensorConfig`, `validateSensorConfig`, `getAvailableSensorTypes`

## 2. 관련 파일과 주요 함수

| 파일 | 역할 |
|------|------|
| `LowFrequencyChart.jsx` | 컨테이너 |
| `hooks/useLowFrequencySensorData.js` | 다중 센서 통합 조회 |
| `LowFrequencyChartManager.jsx` | 옵션 선택·MainChart |
| `realtime/RealtimeChart.jsx` | 실시간 |
| `period/PeriodChart.jsx` | 기간 |
| `sensors/index.js` | 센서 config 라우팅 |
| `sensors/*SensorConfig.js` | 타입별 dataProcessor |

---

## 3. 사용 컴포넌트 설명

| 컴포넌트 | 설명 |
|----------|------|
| `LowFrequencyChart` | Bento 저빈도 차트 |
| `LowFrequencyDashboardChart` | 대시보드 래퍼 |
| `SensorStackedBarChart` / `SensorValueBarChart` | siteConfig 변형 차트(상세 진입 포함) |

---

## 4. 구현 시 주의사항

1. 핵심은 `dataProcessor` 입출력 계약 — Realtime/Period 양쪽 검증.
2. 소켓 포맷 변경 시 `useLowFrequencySensorData` 경유 전체 영향.
3. Realtime/Period 패턴을 한쪽만 독립 수정하지 않는다.
