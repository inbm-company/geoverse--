# 03. 대시보드 및 모니터링

## 3.1 대시보드 개요

### 기능 설명

로그인 후 가장 먼저 보이는 메인 화면이다. 현장에 설치된 센서의 **최신 측정값**을 게이지·숫자·차트·목록 등으로 보여 주며, 일정 간격으로 자동 갱신된다.

현장마다 배치 방식이 다르다.

| 유형 | 특징 |
| --- | --- |
| **고정형 레이아웃** | 미리 정해진 카드·게이지 배치. 조감도(현장 지도)와 연동되는 현장이 많다. |
| **그리드형 레이아웃** | 위젯을 드래그·크기 조절로 배치. 관리자가 구성한 위젯 목록을 표시한다. |
| **모바일 전용** | 일부 현장은 휴대폰 화면에 맞춘 단순 레이아웃을 사용한다. |

### 화면 구성

| 영역 | 설명 |
| --- | --- |
| 상단 헤더 | 현장명, 관리 메뉴, 테마, 사용자 |
| 본문 | 센서·위젯 표시 영역 |
| 하단 푸터 | 고정 안내·정보 |

---

## 3.2 실시간 값 표시

### 기능 설명

센서에서 새 데이터가 들어오면 대시보드의 숫자·게이지·색상이 갱신된다. 사용자가 새로고침하지 않아도 최신 상태를 볼 수 있다.

### 표시 규칙

| 조건 | 화면 |
| --- | --- |
| 기준치 미설정 | 측정값만 표시, 기본 색 |
| 정상 범위 | 기본 색 |
| 1차 기준 초과 | 주의 색(노란 계열) |
| 2·3차 기준 초과 | 위험 색(빨간 계열) |

기준치 설정 방법은 [07-기준치-알림-엑셀.md](./07-기준치-알림-엑셀.md)를 본다.

### 예외 처리

- 통신이 끊기면 마지막으로 받은 값이 유지되거나, 값 없음 상태로 표시될 수 있다.
- 데이터가 아직 한 번도 들어오지 않은 센서는 빈 값 또는 대기 표시가 나온다.

---

## 3.3 게이지·목록·차트 위젯

### 기능 설명

그리드형 대시보드에서는 위젯마다 표시 형태가 다르다. 관리자가 위젯 설정에서 선택한 방식에 따라 아래 중 하나 이상으로 보인다.

| 표시 형태 | 설명 |
| --- | --- |
| 게이지 | 원형 또는 막대형으로 현재값과 상태 색 |
| 목록 | 여러 채널·항목을 한 카드에 나열 |
| 막대 차트 | 항목별 비교 |
| 시계열 차트 | 짧은 구간 추이 |
| CCTV | 등록된 카메라 영상 |

### 사용 절차

1. 대시보드 본문에서 위젯 카드를 확인한다.
2. 숫자·색으로 현재 상태를 파악한다.
3. 자세한 기간 조회가 필요하면 카드를 클릭해 [04-상세-조회.md](./04-상세-조회.md) 화면으로 이동한다.

### 예외 처리

- **조감도·현장정보·센서 근황** 등 고정 정보 위젯은 상세 조회 대상이 아니다.
- **CCTV** 위젯은 영상만 표시하고 상세 조회로 열리지 않는다.
- **모바일**에서는 위젯 상세 조회가 제공되지 않는다.

---

## 3.4 그리드 배치 (그리드형 현장)

### 기능 설명

관리자·사용자가 위젯 카드의 위치와 크기를 바꿀 수 있다. 변경 내용은 브라우저에 저장되어 같은 PC에서 다시 접속해도 유지된다.

### 사용 절차

1. 위젯 카드 가장자리 또는 빈 영역을 드래그한다.
2. 원하는 위치에 놓거나 크기를 조절한다.
3. 페이지를 새로고침해도 배치가 유지된다.

---

## 3.5 조감도·마커 (고정형 현장)

### 기능 설명

일부 현장은 현장 전경 이미지(조감도) 위에 센서 위치를 **마커**로 표시한다. 마커를 클릭하면 해당 센서의 상세 조회 화면이 열린다.

### 사용 절차

1. 조감도에서 마커를 클릭한다.
2. 연결된 센서의 상세 조회가 열린다.

### 표시 규칙 (관리 기능)

- 권한이 있는 사용자는 마커 위치를 드래그해 옮길 수 있으며, 저장하면 다른 사용자 화면에도 반영된다.

---

## 3.6 상단 헤더 정보

### 기능 설명

현재 보고 있는 현장 이름과 시스템명을 표시한다. 현장마다 제목·부제가 다르게 설정될 수 있다.

### 화면 구성

| 항목 | 설명 |
| --- | --- |
| 시스템명 | 「지오버스 통합 모니터링 시스템」 |
| 현장명 | 해당 현장 이름 |
| 부제 | 현장 부가 표기 (있을 경우) |

---

## 3.7 GeoEco 전용 화면

### 기능 설명

일부 GeoEco 현장은 별도 주소(`/geoeco`)로 접속하는 전용 대시보드를 사용한다. 위젯 그리드 형태로 센서 카드를 표시한다.

### 사용 절차

1. GeoEco 전용 URL로 접속한다.
2. 해당 현장의 위젯 카드가 표시된다.
3. 카드 클릭 등 상세 조회는 그리드형 현장과 동일한 방식으로 동작한다.
