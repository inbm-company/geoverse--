# 01. 시스템 개요

## 1.1 시스템명

**Geoverse 통합 모니터링 시스템**

현장에 설치된 센서 데이터를 실시간으로 확인하고, 기간별 추이를 차트와 표로 조회하며, 관리자가 장치·위젯·기준치를 설정할 수 있는 웹 기반 모니터링 시스템이다.

## 1.2 주요 목적

- 여러 현장의 센서 상태를 한 화면에서 확인
- 측정값이 기준을 넘으면 색상·알림으로 위험을 인지
- 관리자가 화면 구성(위젯 배치·표시 방식)을 현장에 맞게 변경
- 과거 데이터를 기간별로 조회·출력(인쇄, 엑셀)

## 1.3 사용자 구분

| 구분 | 설명 | 대표 기능 |
| --- | --- | --- |
| **일반 사용자** | 로그인한 모든 사용자 | 대시보드 보기, 상세 조회, 기준치 설정, 알림 로그 |
| **관리자** | 현장 운영 담당 | 위젯 관리, 사용자 관리 |
| **최고 관리자** | 시스템 전체 설정 담당 | 디바이스 등록, 디바이스·센서 종류 목록 관리 (관리자 기능 포함) |

권한에 따라 상단 메뉴에 보이는 항목이 달라진다. 자세한 내용은 [02-로그인-및-권한.md](./02-로그인-및-권한.md)를 본다.

## 1.4 전체 화면 구성

로그인 후 기본 화면은 다음과 같이 구성된다.

```text
┌─────────────────────────────────────────────┐
│  상단 헤더 (현장명, 메뉴, 테마, 사용자)        │
├─────────────────────────────────────────────┤
│                                             │
│  본문 — 대시보드 (현장마다 레이아웃 상이)       │
│  · 게이지, 차트, 목록, 조감도, CCTV 등        │
│                                             │
├─────────────────────────────────────────────┤
│  하단 푸터                                   │
└─────────────────────────────────────────────┘
```

메뉴·설정·상세 조회는 화면 위에 **드로어(측면 패널)** 형태로 열린다. 본문을 가리지 않고 옆에서 슬라이드되어 나타난다.

## 1.5 주요 기능 영역

| 영역 | 문서 | 요약 |
| --- | --- | --- |
| 로그인·권한 | 02 | 접속, 메뉴 노출 |
| 대시보드 | 03 | 실시간 모니터링, 조감도 |
| 상세 조회 | 04 | 기간별 차트·기록·엑셀 |
| 위젯 관리 | 05 | 화면에 무엇을 어떻게 보일지 설정 |
| 디바이스·센서 | 06 | 측정 장치와 센서 종류 등록 |
| 기준치·알림 | 07 | 위험 기준, 알림 이력 |

## 1.6 현장별 화면 차이

현장마다 대시보드 모양이 다를 수 있다. 예를 들어 일부 현장은 고정된 카드형 레이아웃을, 다른 현장은 사용자가 배치·크기를 바꿀 수 있는 그리드형 레이아웃을 사용한다.

공통적으로 다음은 동일하다.

- 상단 헤더와 메뉴
- 센서 클릭 시 상세 조회
- 기준치·알림 로그 메뉴
- 실시간 값 갱신

현장별 레이아웃 차이는 [03-대시보드-및-모니터링.md](./03-대시보드-및-모니터링.md)에서 설명한다.
