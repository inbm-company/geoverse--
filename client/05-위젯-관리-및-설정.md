# 05. 위젯 관리 및 설정

## 5.1 위젯 관리자 개요

### 기능 설명

관리자가 **대시보드에 무엇을 어떻게 보일지** 구성하는 화면이다. 사용 가능한 센서·CCTV 목록에서 항목을 끌어 **그룹(위젯)** 으로 묶고, 각 그룹의 표시 이름·표시 방식·계산 옵션을 설정한 뒤 저장한다.

저장이 완료되면 그리드형 대시보드에 위젯 카드가 나타나거나 갱신된다.

### 화면 구성

| 영역 | 설명 |
| --- | --- |
| 왼쪽 목록 | 아직 그룹에 넣지 않은 센서·CCTV |
| 오른쪽 그룹 패널 | 만들어진 위젹 그룹 목록 |
| 상단 | 저장, 닫기 |

---

## 5.2 위젯 관리자 열기

### 사용 절차

1. 상단 메뉴 **위젯 관리자**를 클릭한다. (관리자 권한 필요)
2. 왼쪽에 배치 가능한 센서·CCTV, 오른쪽에 기존 그룹이 표시된다.

### 예외 처리

- 권한이 없으면 메뉴가 보이지 않는다.
- 저장하지 않고 닫으려 할 때 변경 내용이 있으면 확인 메시지가 나온다.

---

## 5.3 그룹 만들기·센서 배치

### 기능 설명

센서나 CCTV를 드래그하여 그룹에 넣으면 하나의 위젯(대시보드 카드)이 된다. 한 그룹에는 **같은 종류의 센서**만 묶는 것이 원칙이다.

### 사용 절차

1. 왼쪽 목록에서 센서(또는 CCTV)를 드래그한다.
2. 오른쪽 기존 그룹 위에 놓거나, 「새 그룹」 영역에 놓는다.
3. 새 그룹이 만들어지면 이름을 확인·수정한다.
4. 그룹에서 센서를 빼려면 왼쪽 목록 쪽으로 다시 드래그한다.

### 표시 규칙

- 그룹 헤더를 드래그하면 **그룹 순서**를 바꿀 수 있다.
- CCTV는 CCTV 전용 그룹에만 넣을 수 있다.

---

## 5.4 그룹 이름·삭제

### 기능 설명

그룹마다 대시보드에 표시될 이름이 있다. 새 그룹을 만들면 센서 종류 이름 등이 자동으로 채워질 수 있다.

### 사용 절차

1. 그룹 이름을 클릭해 수정한다.
2. 그룹을 없애려면 **삭제**를 선택한다. (확인 후 그룹이 사라지고 센서는 왼쪽 목록으로 돌아간다.)

---

## 5.5 형제 위젯

### 기능 설명

같은 그룹 안에서 채널별로 **별도 카드**처럼 나뉘어 보이게 하는 옵션이다. 하나의 그룹이 대시보드에서 여러 카드로 펼쳐질 때 사용한다.

### 사용 절차

1. 그룹 설정에서 **형제 위젯** 옵션을 켜거나 끈다.
2. 저장 후 대시보드에서 카드가 분리·통합되어 표시된다.

---

## 5.6 위젯 설정 (표시·계산)

### 기능 설명

그룹별로 **어떤 형태로 보일지**, **어떤 항목을 계산할지** 상세 설정한다. 설정 화면은 센서 종류에 따라 입력 항목이 다르다.

### 화면 구성 (공통)

| 항목 | 설명 |
| --- | --- |
| 위젯 이름 | 대시보드 카드 제목 |
| 표시 형태 | 게이지, 목록, 막대 차트, 시계열 차트 등 |
| 센서 목록 | 그룹에 포함된 센서·채널 |
| 항목별 이름 | 표·차트에 보이는 열 이름 |
| 계산식 | 초기치·보정값 반영 등 (해당 센서) |

### 센서 종류별 설정 예

| 종류 | 설정 내용 예 |
| --- | --- |
| 다채널 무선 센서 | 채널별 항목, 단일 출력 여부 |
| 지중경사계 | 깊이별 항목, 축(A/B), 누적 방향 |
| 계산형 센서 | 수식, 입력 변수 |
| 고주파 센서 | 채널·주파수 관련 옵션 |

### 사용 절차

1. 그룹의 **설정** 버튼을 연다.
2. 표시 형태·센서 항목·계산식 등을 입력한다.
3. **저장**한다.
4. 위젯 관리자로 돌아와 전체 **저장**을 한 번 더 눌러 반영한다.

### 예외 처리

- 항목 이름을 비우면 데이터 키 이름 등 기본값이 채워질 수 있다.
- 저장 전에 닫으면 변경이 반영되지 않는다.

---

## 5.7 CCTV 카메라 관리

### 기능 설명

CCTV 위젯에 넣을 카메라 목록을 등록·수정·삭제한다. 이름과 영상 주소(URL)를 관리한다.

### 사용 절차

1. 위젯 관리자 왼쪽 **CCTV** 영역에서 카메라를 추가·수정한다.
2. CCTV 그룹에 카메라를 드래그해 배치한다.
3. 저장한다.

### 예외 처리

- 이미 위젯에 사용 중인 카메라는 삭제 시 안내가 나올 수 있다.

---

## 5.8 저장

### 기능 설명

그룹 구성·순서·설정 변경은 **저장** 버튼을 눌러야 서버에 반영된다.

### 사용 절차

1. 변경 후 하단 **저장**을 클릭한다.
2. 「저장 중…」 표시 후 완료되면 대시보드 위젯이 갱신된다.

### 예외 처리

- 저장 실패 시 오류 안내가 표시되고, 화면의 편집 내용은 유지된다.
- 「저장되지 않은 변경이 있습니다」 문구가 있으면 아직 반영되지 않은 상태이다.

---

## 5.9 대시보드와의 관계

| 관리자 작업 | 사용자 화면 |
| --- | --- |
| 그룹 생성·센서 배치 | 새 위젯 카드 표시 |
| 표시 형태 변경 | 게이지 ↔ 차트 등 카드 모양 변경 |
| 그룹 순서 변경 | 카드 배치 순서 변경 (그리드형) |
| 그룹 숨김·삭제 | 카드 사라짐 |

일반 사용자는 위젯 관리자에 들어가지 않고, 저장된 결과만 대시보드에서 본다.
