# 06. 디바이스 및 센서 등록

## 6.1 개요

### 기능 설명

최고 관리자가 **현장 구조**, **측정 장치(디바이스)**, **센서·디바이스 종류 목록**을 등록·수정한다. 여기서 등록한 내용이 위젯 관리·대시보드·상세 조회의 기반이 된다.

일반 사용자·관리자는 이 메뉴를 사용하지 않는다.

---

## 6.2 디바이스 관리자

### 기능 설명

현장을 트리 구조로 관리한다. 최상위 **프로젝트·노드**, 그 아래 **폴더**, 말단 **디바이스**로 계층을 이룬다.

### 화면 구성

| 요소 | 설명 |
| --- | --- |
| 트리 | 노드 · 폴더 · 디바이스 계층 |
| 추가·수정 폼 | 선택한 항목의 이름, 설명, 종류 등 |
| 채널 패널 | 디바이스 선택 시 채널·센서 배정 |

### 사용 절차 — 구조 추가

1. 상단 **디바이스 관리자**를 연다.
2. **프로젝트 추가** 또는 노드·폴더·디바이스 **추가**를 선택한다.
3. 이름·설명 등을 입력하고 저장한다.
4. 디바이스 추가 시 **종류**(디바이스목록에서 정의)를 선택한다.

### 사용 절차 — 디바이스 이동

1. 디바이스 옆 **드래그 핸들**을 잡는다.
2. 다른 폴더 또는 노드 직속 위치에 놓는다.
3. 저장되면 해당 위치 소속으로 바뀐다.

### 표시 규칙

- 새 디바이스 이름은 종류 이름 + 순번 형태로 자동 제안될 수 있다 (예: 지중경사계1).
- 새 노드·폴더는 「노드 1」「폴더 1」처럼 순번 이름이 제안될 수 있다.

### 예외 처리

- 최상위 노드가 없으면 「최상위 노드 추가」 안내가 표시된다.
- 폴더 삭제 시 안의 디바이스는 상위 노드 직속으로 옮겨질 수 있다.

---

## 6.3 디바이스 채널 설정

### 기능 설명

디바이스 하나에 여러 **채널**이 있을 수 있다. 채널마다 어떤 **센서 종류**를 쓰는지, 채널 이름·그룹을 지정한다.

### 화면 구성

| 항목 | 설명 |
| --- | --- |
| 채널 목록 | 번호·이름·연결 센서 종류 |
| 채널 그룹 | 여러 채널을 묶는 이름 |
| 센서 종류 선택 | 센서목록에 등록된 종류 중 선택 |

### 사용 절차

1. 트리에서 디바이스를 선택한다.
2. 오른쪽 채널 패널에서 채널을 추가·수정한다.
3. 센서 종류를 선택하고 이름을 확인한다.
4. 저장한다.

### 표시 규칙

- 디바이스 **모델**(무선, 지중경사, 계산형 등)에 따라 선택 가능한 센서 종류 목록이 필터링된다.

---

## 6.4 디바이스목록 (디바이스 종류)

### 기능 설명

현장에 설치할 수 있는 **디바이스 종류**를 정의한다. 채널 개수, 통신 방식 등 공통 속성을 관리한다.

### 사용 절차

1. 상단 **디바이스목록**을 연다.
2. 종류를 추가·수정·삭제한다.
3. 채널 수, 모델명 등을 입력하고 저장한다.

### 예외 처리

- 이미 현장에 사용 중인 종류는 삭제가 제한될 수 있다.

---

## 6.5 센서목록 (센서 종류)

### 기능 설명

측정 **센서 종류**와 기본 옵션을 정의한다. 위젯을 새로 만들 때 이 기본값이 채워진다.

### 화면 구성

| 항목 | 설명 |
| --- | --- |
| 종류 이름 | 관리·선택용 이름 |
| 통신·파싱 방식 | 무선, 지중경사, 계산형, 고주파 등 |
| 기본 옵션 | 항목 구조, 계산식 예시 등 |

### 사용 절차

1. 상단 **센서목록**을 연다.
2. 센서 종류를 추가하거나 기존 항목을 수정한다.
3. 종류에 맞는 기본 필드를 입력하고 저장한다.

### 표시 규칙

| 통신·측정 방식 | 설정 화면 예 |
| --- | --- |
| 다채널 무선 | 채널 수, 출력 방식 |
| 지중경사 | 깊이·축 항목 |
| 계산형 | 수식·변수 |
| 고주파 | FFT 관련 옵션 |

---

## 6.6 등록 정보의 활용

| 등록 단계 | 이후 사용 |
| --- | --- |
| 디바이스목록 · 센서목록 | 디바이스·채널 추가 시 선택지 |
| 디바이스 관리자 | 실제 장치 등록, 트리 구조 |
| 위젯 관리자 | 등록된 센서를 그룹·위젯으로 배치 |
| 대시보드 | 위젯을 통해 측정값 표시 |

등록 순서는 보통 **종류 정의 → 디바이스 등록 → 위젯 구성** 순이다.

---

## 6.7 시스템 모니터

### 기능 설명

최고 관리자가 현장명 영역을 더블클릭하면 열리는 **시스템 상태 확인** 화면이다. 운영·장애 확인용이다.

### 사용 절차

1. 최고 관리자 계정으로 로그인한다.
2. 상단 현장명 영역을 **더블클릭**한다.
3. 시스템 모니터 화면을 확인한다.
