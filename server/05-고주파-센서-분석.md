# 05. 고주파 센서 분석 (FFT)

## 5.1 개요

### 기능 설명

가속도계·장력계에서 올라온 **고주파 원시 데이터(50Hz, 10분 단위)** 를 받아 분석하고, 그 결과를 관제 시스템으로 전달하는 별도 분석 서버다.

- 센서가 만든 압축 파일(ZIP)을 받아 자동으로 풀고 내용을 읽는다.
- 센서 종류에 맞는 계산(케이블 장력 / 가속도 / 원시 통계)을 수행한다.
- 계산 결과와 함께 **시간 그래프·주파수(FFT) 그래프 이미지**를 만들어 저장한다.
- 최종 측정값을 **MQTT**로 발행해, 대시보드·상세 조회 화면에서 볼 수 있게 한다.

사용자가 직접 조작하는 화면은 없고, 센서 수집기 또는 운영자가 파일을 올리면 나머지는 자동으로 처리된다. 대시보드의 「고주파(FFT)」 위젯에 표시되는 값과 이미지가 이 서버의 산출물이다.

---

## 5.2 데이터 수집

### 기능 설명

분석할 원시 데이터를 서버로 들여오는 방법은 두 가지다.

| 방식 | 설명 | 사용 상황 |
| --- | --- | --- |
| 파일 업로드 | 외부에서 ZIP 파일을 서버로 전송 | 상시 운영 (현재 주 경로) |
| 자동 다운로드 | 서버가 수집 서버에서 파일을 직접 내려받음 | 배치 처리·보완 수집 |

### 입력·출력

| 항목 | 설명 |
| --- | --- |
| 입력 | 센서 데이터가 들어 있는 ZIP 파일 1개 |
| 출력 | 축별 분석 결과, 차트 이미지 주소, MQTT 발행 여부 |

### 처리 절차 (업로드)

1. 수집기가 ZIP 파일을 분석 서버로 전송한다.
2. 서버가 파일명을 해석해 센서 ID·채널·축·센서 종류를 알아낸다.
3. 파일을 센서별 폴더에 저장하고 압축을 푼다.
4. 센서에 맞는 계산을 수행한다.
5. 결과를 MQTT로 발행하고, 처리 요약을 응답으로 돌려준다.

### 처리 절차 (자동 다운로드)

1. 등록된 센서 목록을 순회한다.
2. 현재 시각 기준 직전 10분 구간의 파일명을 만들어 수집 서버에서 내려받는다.
3. 이미 받은 파일이면 건너뛴다.
4. 내려받은 파일을 압축 해제 후 동일하게 분석·발행한다.

### 예외 처리

- ZIP이 아닌 파일은 거부한다.
- 같은 이름의 파일이 이미 있으면 파일명 뒤에 초 단위를 붙여 따로 보관한다.
- 다운로드 실패 시 최대 3회까지 간격을 늘려 가며 재시도하고, 파일이 없으면(404) 즉시 다음 센서로 넘어간다.
- 모든 센서 다운로드가 실패하면 처리를 중단하고 실패 사유를 남긴다.

## 5.3 파일명 규칙

### 기능 설명

별도 입력 화면이 없으므로 **파일명이 곧 분석 파라미터**다. 파일명만 규칙에 맞으면 서버가 스스로 처리 방식을 결정한다.

### 표시 규칙

```
{센서ID}_{센서종류}_{축}_{채널}_{측정시각}.zip
예) geocus900_1000_01_tension_z_ch1_202603311450.zip
```

| 항목 | 값 | 설명 |
| --- | --- | --- |
| 센서ID | 자유 문자열 | 언더스코어 포함 가능 |
| 센서종류 | `acc` / `tension` | 가속도계 / 장력계 |
| 축 | `x`, `y`, `z`, `xy`, `xz`, `yz`, `xyz` | 분석할 축 조합 |
| 채널 | `ch1`, `ch2` … | 센서 채널 |
| 측정시각 | 12자리 `YYYYMMDDHHMM` | 데이터 기준 시각 |

### 예외 처리

- 항목이 5개 미만이면 업로드가 거부된다.
- 측정시각이 12자리 숫자가 아니거나 채널 형식이 다르면 거부된다.
- 센서종류가 `acc`·`tension`이 아니면 거부된다.
- 축 값이 표준 조합이 아니면 경고만 남기고 처리는 계속한다.

## 5.4 압축 해제 및 데이터 읽기

### 기능 설명

ZIP 안에 들어 있는 센서 기록 파일을 찾아 축별 시계열로 변환한다.

### 처리 절차

1. ZIP 무결성을 검사한 뒤 임시 폴더에 푼다.
2. 풀린 파일 중 `.txt` 또는 `.json` 파일을 센서 데이터로 인식한다.
3. 내부 구조를 자동 판별해 지정된 축의 값만 뽑아낸다.
4. 분석이 끝나면 임시 폴더를 자동 삭제해 저장 공간을 확보한다.

### 표시 규칙

| 데이터 형태 | 예시 구조 | 처리 |
| --- | --- | --- |
| 배열형 | `{"time":…, "data":[[x,y,z], …]}` | 축 위치로 값 추출 |
| 객체형 | `{"time":…, "data":[{"x":…,"y":…,"z":…}]}` | 축 이름으로 값 추출 |
| 표(CSV)형 | X/Y/Z 컬럼 | 해당 컬럼 추출 |

1초 블록이 10분치 이어 붙어 하나의 연속 시계열(50Hz 기준 약 30,000 샘플)이 된다.

### 예외 처리

- 손상된 ZIP이거나 센서 데이터 파일이 없으면 처리를 중단한다.
- 배열형 해석에 실패하면 객체형·CSV 순으로 다시 시도한다.
- 요청한 축의 값이 하나도 없으면 해당 축만 실패로 기록하고 나머지 축은 계속 처리한다.

## 5.5 분석 방식 자동 선택

### 기능 설명

같은 가속도 데이터라도 현장에 따라 **장력을 뽑을지, 진동수를 뽑을지, 통계만 낼지**가 다르다. 서버는 센서ID+채널을 기준으로 어떤 계산을 쓸지 스스로 결정한다.

### 처리 절차

1. 내부에 미리 정의된 센서별 설정이 있으면 그것을 우선 사용한다.
2. 없으면 외부 설정 서버에 센서ID·채널로 질의해 계산 방식과 파라미터를 받아온다.
3. 그래도 결정되지 않으면 기본값인 **케이블 장력 계산**을 적용한다.

### 표시 규칙

| 계산 방식 | 산출값 | 대상 |
| --- | --- | --- |
| 케이블 장력 | 장력(kN) | 장력 계측 대상 케이블 |
| 가속도 분석 | 고유진동수(Hz), 최대·최소·평균 가속도 | 진동 계측 |
| 원시 가속도 | 최대·최소·평균 가속도 | 통계만 필요한 경우 |

한 센서에 계산 방식이 여러 개 지정될 수 있으며, 이 경우 순서대로 모두 수행한다.

### 예외 처리

- 외부 설정 서버 조회는 2회까지 재시도한다.
- 알 수 없는 계산 방식이 지정되면 기본값(케이블 장력)으로 대체한다.
- 케이블 길이·단위중량 등 파라미터가 잘못된 형식이면 오류로 처리한다.

## 5.6 케이블 장력 계산

### 기능 설명

케이블의 진동에서 기본 진동수를 찾아내 **실제 장력(kN)** 을 역산한다.

### 처리 절차

1. 축 데이터를 50Hz 기준으로 맞춘다.
2. 튀는 값(글리치)을 주변 값 기준으로 보정한다.
3. 0.5~22Hz 대역만 남기고 걸러낸다.
4. FFT로 주파수 스펙트럼을 만든다.
5. 스펙트럼에서 봉우리(피크)를 찾는다.
6. 2~8Hz 범위에서 기본 진동수 후보를 훑어, 배음(2배·3배…)이 가장 잘 맞는 값을 고른다.
7. 확정된 배음들로 회귀 계산해 기본 진동수를 정밀화한다.
8. 케이블 길이와 단위중량을 적용해 장력을 계산한다.

### 입력·출력

| 구분 | 항목 |
| --- | --- |
| 설정 입력 | 케이블 길이(m), 단위중량(kN/m), 케이블 명칭 |
| 결과 출력 | 장력(N·kN), 적합도(R²), 사용된 모드 개수 |
| 이미지 출력 | 시간 그래프, FFT 그래프(피크·배음 표시) |

### 예외 처리

- 유효한 피크를 찾지 못하면 「진동 신호 강도가 부족하다」는 안내와 함께 해당 축을 실패 처리한다.
- 계산에 실패해도 **시간 그래프는 생성**해 원신호를 눈으로 확인할 수 있게 한다.
- 여러 축 중 일부만 실패하면 성공한 축의 결과는 그대로 발행한다.

## 5.7 가속도 분석

### 기능 설명

구조물의 **고유진동수와 가속도 크기**를 확인한다.

### 처리 절차

1. 원시값(g)을 가속도 단위(m/s²)로 바꾼다.
2. 최대·최소·평균 가속도를 구한다.
3. 평균을 제거하고 0.5~24.5Hz 대역만 남긴다.
4. FFT를 수행하고, 가장 큰 봉우리의 주파수를 고유진동수로 삼는다.

### 입력·출력

| 구분 | 항목 |
| --- | --- |
| 결과 출력 | 고유진동수(Hz), 최대·최소·평균 가속도(m/s²) |
| 이미지 출력 | 원신호 시간 그래프, FFT 그래프(최대 피크 주파수 표기) |

### 예외 처리

- 피크가 하나도 없으면 고유진동수를 0으로 기록하고 통계값만 남긴다.
- X·Y·Z를 모두 지정한 경우 축마다 개별 분석·개별 차트를 만든다.

## 5.8 원시 가속도 분석

### 기능 설명

주파수 분석 없이 **가속도 통계값만** 빠르게 산출한다. 진동 특성보다 크기 감시가 목적인 센서에 사용한다.

### 입력·출력

| 구분 | 항목 |
| --- | --- |
| 결과 출력 | 최대·최소·평균 가속도 |
| 이미지 출력 | 원신호 시간 그래프 1장 |

## 5.9 차트 이미지 생성

### 기능 설명

분석 결과를 대시보드·상세 조회 화면에 바로 끼워 넣을 수 있도록 **가로로 긴 요약형 그래프 이미지**를 만든다.

### 표시 규칙

| 항목 | 규칙 |
| --- | --- |
| 크기 | 1,500 × 300 픽셀 (가로 5 : 세로 1) |
| 구성 | 제목·축 이름·범례 없음, 가로 눈금선만 표시 |
| 테두리 | 아래쪽만 표시 |
| 강조 | FFT 그래프는 주요 피크 위에 주파수 값을 숫자로 표기 |
| 파일명 | `{센서ID}_{채널}_{측정시각}_{그래프종류}_{축}.png` |

### 그래프 종류

| 종류 | 내용 | 생성 계산 |
| --- | --- | --- |
| 시간 그래프 | 시간에 따른 원신호 변화 | 전체 |
| FFT 그래프 | 주파수별 진폭과 검출 피크 | 장력 / 가속도 |
| 장력 FFT 요약 | 피크·배음선·회귀 기본진동수 함께 표시 | 장력 |

### 처리 절차

1. 계산이 끝나면 그래프를 만들어 센서ID·채널별 폴더에 저장한다.
2. 저장 경로를 웹 주소로 바꿔 응답에 담는다.
3. 화면에서는 이 주소를 그대로 이미지로 불러 표시한다.

### 예외 처리

- 그래프 생성에 실패해도 계산 결과는 정상 발행한다.
- 실제로 저장된 파일만 주소로 제공한다.

## 5.10 결과 발행 (MQTT)

### 기능 설명

계산된 측정값을 관제 시스템이 받을 수 있도록 MQTT 메시지로 내보낸다. 이 값이 대시보드 게이지와 상세 조회 표에 쌓인다.

### 입력·출력

| 항목 | 설명 |
| --- | --- |
| 발행 내용 | 센서ID, 채널, 측정시각, 축별 최대·최소·평균, 단위 |
| 측정시각 | 파일명의 측정시각을 한국시간(KST)으로 변환해 사용 |

### 표시 규칙

| 계산 방식 | 발행 값 | 단위 |
| --- | --- | --- |
| 케이블 장력 | 장력값 (최대·최소·평균 동일) | kN |
| 가속도 분석 | 고유진동수 + 가속도 통계 | Hz/g |
| 원시 가속도 | 가속도 통계 | g |

### 처리 절차

1. 같은 계산 방식으로 처리한 여러 축의 결과를 **하나의 메시지로 합친다.**
2. 브로커에 접속해 메시지를 발행한다.
3. 발행 성공 여부를 결과에 함께 기록한다.

### 예외 처리

- 발행에 실패하면 2초 간격으로 최대 3회 재시도한다.
- 끝내 실패해도 계산 결과와 그래프는 서버에 남아 있어 다시 확인할 수 있다.
- 발행 실패는 응답에 「미발행」으로 표시된다.

## 5.11 처리 결과 응답

### 기능 설명

업로드 한 건에 대한 처리 요약을 즉시 돌려준다.

### 입력·출력

| 항목 | 설명 |
| --- | --- |
| 처리 상태 | 성공 / 실패 |
| 센서 정보 | 센서ID, 채널, 적용된 계산 방식 |
| 축별 결과 | 계산값, 그래프 주소, 발행 여부 |
| 처리 요약 | 성공 축 수 / 전체 축 수 |
| 오류 목록 | 일부 축이 실패한 경우 사유 |

### 예외 처리

| 상황 | 처리 |
| --- | --- |
| 파일명 형식 오류 | 요청 거부, 올바른 형식 안내 |
| 신호 부족·피크 없음·데이터 없음 | 데이터 품질 문제로 안내 |
| 그 외 내부 오류 | 서버 오류로 처리하고 로그에 상세 기록 |
| 일부 축만 실패 | 성공한 축은 정상 처리하고 실패 사유를 함께 반환 |

### 기능 설명

운영자가 서버와 수집 상태를 점검할 수 있는 조회 기능이다.

| --- | --- |
| 헬스체크 | 서버 동작 여부와 현재 시각 |
| 분석 설정 상태 | 적용 중인 케이블·분석 파라미터 |
| 수집 상태 | 등록 센서 목록, 다음 대상 파일명, 스케줄러 동작 여부 |

## 5.13 저장소 관리

### 기능 설명

원본과 산출물을 종류별로 나눠 보관하고, 불필요한 임시 파일은 자동 정리한다.

| 보관 대상 | 위치 기준 | 정리 |
| --- | --- | --- |
| 업로드 원본 ZIP | 센서ID·채널별 폴더 | 보관 |
| 압축 해제 임시 파일 | 파일별 임시 폴더 | 분석 직후 자동 삭제 |
| 시간 그래프 | 분석 종류별 폴더 | 보관 |
| FFT 그래프 | 분석 종류별 폴더 | 보관 |

생성된 그래프는 웹 주소로 공개되어 대시보드·상세 조회·인쇄 화면에서 그대로 불러 쓴다.

## 5.14 분석 유형별 차이 요약

| 구분 | 주 산출값 | 그래프 | 발행 단위 |
| --- | --- | --- | --- |
| 케이블 장력 | 장력(kN), 적합도 | 시간 + FFT(배음 표시) | kN |
| 가속도 분석 | 고유진동수, 가속도 통계 | 시간 + FFT | Hz/g |
| 원시 가속도 | 가속도 통계 | 시간 | g |

센서 종류와 무관하게 **파일 수신 → 압축 해제 → 계산 → 그래프 생성 → 결과 발행** 흐름은 동일하다.

## 부록 C. 주요 기본 파라미터

| 구분 | 항목 | 기본값 |
| --- | --- | --- |
| 공통 | 샘플링 주파수 | 50 Hz |
| 공통 | 데이터 길이 | 10분 (약 30,000 샘플) |
| 공통 | 중력 가속도 | 9.80665 m/s² |
| 장력 | 대역통과 필터 | 0.5 ~ 22 Hz (4차) |
| 장력 | 기본 진동수 탐색 범위 | 2 ~ 8 Hz |
| 장력 | 최대 배음 차수 | 12차 (22 Hz 이내) |
| 장력 | 글리치 제거 | 윈도우 9샘플, 3σ |
| 가속도 | 대역통과 필터 | 0.5 ~ 24.5 Hz (4차) |
| 수집 | 다운로드 재시도 | 3회 (지수 백오프) |
| 발행 | MQTT 재시도 | 3회 (2초 간격) |

센서별 케이블 길이·단위중량은 내부 설정 또는 외부 설정 서버 값으로 덮어쓴다.
